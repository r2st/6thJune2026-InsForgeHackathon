Inferred judging rubric

// from sponsor mix + judge profile

The room is dev-tools founders and YC P26 partners. The sponsor stack is InsForge / Vercel / Cognition / Replicas / Limrun — all execution-layer infra. That points at one outcome: judges reward agents that do something visible, on real infra, that another engineer would want to install. Below is the four-axis rubric we should optimize for. Adjust if the host announces a different one.

~30%

Live demo lands

Does it work end-to-end, on stage, on flaky wifi? Open with the wow moment in the first 30 seconds. Pre-record a fallback. Never blame the network.

~25%

Agentic core

Is the agent doing something only an agent could do — multi-step, stateful, self-correcting — or is it a prompt with a UI? Single LLM calls lose.

~25%

Sponsor depth

Did you use the sponsor stack in a way the sponsor would brag about? Lighting up 3+ of the five verbs (CAPTURE/EXECUTE/FIX/SURFACE/PERSIST) is the safe bar.

~20%

Engineer-real

Would a working engineer install this on Monday? The room is dev-tools founders — they'll smell a toy. Pain has to be specific and recognized.

Limrun

verb · EXECUTE

Sandboxed code execution. Boot a clean env, run agent-written code, observe the result. The substrate that lets agents actually do rather than describe.

Credits$200–$1,000 in prize tiers — biggest credit pool

Killer move"It re-ran the failing test 200×" — only sandboxes can

Replicas

verb · CAPTURE

Session replay / synthetic user capture. The no-API source of truth for what real users did. Plug into a sample app and you can replay any error path.

Preflight checklist

// before 9 AM Saturday
All five sponsors return a "hello world" 200
InsForge: provision a project, create one table, query it. Vercel: deploy a hello-world function. Devin: trigger a session, get a PR URL back. Limrun: create a sandbox, exec echo hi, fetch output. Replicas: capture a session, fetch as JSON. If any one fails, you'll burn build hours debugging auth on the day.
Wallet ready on phone
Check-in requires wallet token verification. Confirm the wallet that received your registration token is unlocked and accessible before you arrive — venue wifi at 9 AM is unreliable for first-time wallet auth.
Hush pitch (FINAL.html) reviewed by every teammate
Make sure everyone agrees on Hush as the build, with DepWatch as the hot-swap backup. Disagreement at 10:30 burns the first hour of the build.
Local dev env: Node 24, pnpm, Vercel CLI, git, gh
Vercel default runtime is Node 24 LTS. Match locally to avoid prod-only failures. Vercel CLI: npm i -g vercel.
Sponsor credits redeemed where possible
Some sponsors hand out credits at check-in; some require pre-redemption via a code on the Luma page or sponsor dashboard. Check your inbox now.
Toy repo + sample app skeleton committed
For Replay → PR: a Next.js app with a broken endpoint, a passing test suite, and an empty main branch ready to receive PRs. Two hours saved on the day.
Pre-recorded fallback demo video shell
Open OBS or QuickTime, frame the screen, test mic. You'll record the real fallback at T+8h but the rig should already work.
Snacks, water, layers, charger, hotspot
SF June is foggy AM, warm PM. EF venue is air-conditioned aggressively. A hotspot is your insurance against demo-time wifi failure.
Day-of contacts saved to phone
Teammates, AI Nexus host (James Unsworth — Luma DM), sponsor reps (introduce yourself early), Uber/Lyft installed.

What good looks like, on stage

// from prior-event playbook
Open on the pain, not the architecture
First 10 seconds: show a real user hitting a real error. No "we built…" — let the failure speak.
Money shot has a clickable artifact
A receipt URL, a PR link, a green check in CI. Judges can click during Q&A.
Sponsor logos are visible without you naming them
"Deployed on Vercel," "powered by InsForge" — bake into the UI. Judges scan for stack coverage; make it free.
90 seconds, hard cap
Most demos run long and lose. Pitch v0 written before code; rehearsed 3× before stage.
Close on "would I install this Monday?"
End on the customer + the install link, not on a thank-you slide. Judges decide in the last 10 seconds.
