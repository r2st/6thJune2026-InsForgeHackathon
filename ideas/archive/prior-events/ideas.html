Filters every idea below passes

  • Uses all 4 verbs in one run. Skipping a verb leaves a sponsor judge cold.
  • One non‑technical sentence of pain. A judge feels it without context.
  • Action verb with real consequences — FILE, DEPLOY, WRITE, or NOTIFY (architecture §5).
  • Lands on /run/:id — the auditor page with a clickable receipt URL.
  • Cache or pre‑record any live web step. No network demos.

1Authmatic

Healthcare · Rtrvr judges ×2

A nurse drops one prescription PDF; the agent fills UnitedHealth’s prior‑auth portal end‑to‑end and pings the doctor with a receipt URL.

Real customer Dr. Chen’s 4‑clinic primary care group in Oakland — MAs lose ~9 hours/week to UHC + Aetna + CoverMyMeds forms.
The pain Prior auths kill prescriptions and burn out staff; payer portals have no API.
READ‑WEB Rtrvr
Logs into UHC provider portal, captures the live coverage rule for the drug+plan.
EXECUTE Daytona
Parses the prescription PDF, normalizes ICD‑10 and dosage to UHC’s schema.
VERIFY Opsera
Scans the outgoing packet for PHI exposure beyond what the form asks for.
PERSIST Insforge
Stores the case, pgvector‑searches prior approvals, edge fn pings the doctor.
Money shot: split screen — Rtrvr autonomously filling the real UHC form on the left, /run/abc123 on the right with the live payer receipt URL the judge can click.

Not building: real EHR integration, multi‑payer coverage, doctor auth. Mock the inbox; pre‑cache the patient chart.

Stretch sponsors (if time) NEAR AI — PHI runs in TEE, agent returns hardware‑signed attestation (HIPAA gold) Tigris — chart PDFs + insurance cards via presigned URLs Brain2 — doc voice‑dictates “auth Lisinopril for Chen”, triggers the run

2Bug‑Report‑to‑PR Targets Opsera MCP track · up to $500

AI & Tech / DevSecOps

A user‑reported bug becomes a reproduced failure, a security‑scanned fix, and a one‑click‑mergeable PR — without a maintainer opening their IDE.

Real customer Maintainer of a popular 12k‑star OSS lib who closes issues at 11 PM because triage eats every evening.
The pain 90% of bug reports are dupes, env mismatches, or 10‑line fixes — but each one demands the maintainer’s focus.
READ‑WEB Rtrvr
Drives the live app in a browser to reproduce the reported failure end‑to‑end — not the API, the actual UI the user broke on.
EXECUTE Daytona
Clones the repo, writes and runs a fix until both the failing test and Rtrvr’s reproduction pass.
VERIFY Opsera
SAST + dependency + secret scan on the diff; attaches a compliance badge to the PR body.
PERSIST Insforge
Edge fn opens the PR with the Opsera badge, the Rtrvr repro video, and a preview link.
Money shot: bug report posted at 0:30 → live PR at 2:30 with the green Opsera badge and a Rtrvr‑recorded repro GIF embedded in the description. Real PR, scrollable, mergeable.

Not building: triage of real public repos, multi‑repo install, maintainer auth. One toy repo, one canned bug.

Stretch sponsors (if time) Lightsprint — parallel cloud agents ship the PR via gstack (replaces our edge fn) Kalibr — auto‑routes codegen calls when the cheap model fails the tests Render — cron worker polls the issue tracker so the agent runs unattended

3SMB Permit Filer

Other / SMB · Abby’s “Monday test”

Restaurant owner uploads last year’s health‑dept renewal; the agent files this year’s with the city — permit receipt back in 90 seconds.

Real customer Maria, owner of a 14‑seat ramen shop in the Mission — pays an attorney $400/year to renew a permit she can’t legally skip.
The pain Small businesses lose half a day a quarter to government portals that look like 2003 and reject submissions on a comma.
READ‑WEB Rtrvr
Drives the SF permit portal — logs in, opens the renewal form, captures live field requirements.
EXECUTE Daytona
Extracts fields from last year’s PDF, updates dates, runs the city’s field‑validation rules locally.
VERIFY Opsera
PII exposure scan + SQL/PII check on the stored case file before submit.
PERSIST Insforge
Stores prior permits in pgvector for diffing, edge fn emails Maria the receipt.
Money shot: Maria’s phone buzzing on screen with the city’s confirmation email — click through to the live permit page.

Not building: payment, real city auth, multi‑jurisdiction. Demo with a sandbox permit portal we pre‑cached.

Stretch sponsors (if time) Brain2 — Maria says “renew my health permit” from the kitchen, agent fires Tigris — stores last‑year’s permit PDF + receipt long‑term, zero egress Render — cron auto‑files 60 days before expiry so the agent runs without prompting

4Conflict‑Check Counsel

Law

A new client name in → the agent checks state bar, OFAC, and litigation history, drafts the conflict memo, and emails the partner before they finish their coffee.

Real customer Junior associate at a 30‑lawyer litigation boutique who runs conflict checks by hand and dreads OFAC false positives.
The pain Missing a conflict is a malpractice event; checking everything by hand is 45 minutes per onboarding.
READ‑WEB Rtrvr
Drives the state‑bar disciplinary portals (no API) for the client’s named principals; pulls live status.
EXECUTE Daytona
Runs OFAC fuzzy‑match scoring + PACER CSV joins; ranks possible conflicts with confidence.
VERIFY Opsera
PII / compliance scan on the outgoing memo — no client SSN leaks to the email.
PERSIST Insforge
Vectorizes prior matters for similarity search; edge fn emails the partner the memo + audit link.
Money shot: partner’s inbox — a cited memo with the OFAC flag highlighted, and a one‑click “clear to proceed” button that writes the decision back.

Not building: matter management, billing, multi‑tenant. One canned client; cache OFAC.

Stretch sponsors (if time) Apify — ready‑made PACER + news Actors absorb the high‑volume scraping Rtrvr shouldn’t NEAR AI — signed attestation on every memo, the kind compliance teams love Brain2 — partner says “run conflict on Acme Corp” from the car

5Vendor Questionnaire Autofiller

E‑Commerce / B2B SaaS · Abby + JJ (founder)

Sales drops the prospect’s 180‑question security review URL into Slack; the agent fills it overnight from prior answers and pings sales with the link to skim — deal unblocked before stand‑up.

Real customer Head of revenue at a 20‑person SaaS who watches $80k deals stall for two weeks while engineering retypes the same 180 answers into yet another vendor portal.
The pain Vendor security reviews block every enterprise deal, each portal is different, and the answers are 90% reused from last time.
READ‑WEB Rtrvr
Opens the prospect’s portal (Drata, Vanta, OneTrust, custom) and extracts the question list.
EXECUTE Daytona
Runs RAG over the company’s SOC2 doc + prior answer corpus to draft each response with citations.
VERIFY Opsera
Scans drafted answers for over‑disclosure (secrets, internal infra, PII) before anything submits.
PERSIST Insforge
pgvector stores every prior Q/A pair so the next portal fills 40% faster than this one. Rtrvr submits.
Money shot: portal URL pasted → 90 seconds later, the portal’s own “100% complete” screen, every answer cited back to the source doc on the audit page.

Not building: real SOC2 doc ingest, multi‑portal SSO, sales CRM hooks. One canned portal, one canned answer corpus.

Stretch sponsors (if time) Nebius — long‑context Llama for 80‑page SOC2 PDFs without cost bleed Kalibr — routes answer drafting between models, retries when confidence drops Tigris — persists the prior‑answer corpus across deals (the moat)
