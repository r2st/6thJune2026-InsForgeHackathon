Six ideas, ranked by sponsor-stack coverage

  1. Top pick · #1

    Procurement Counter-Intel Agent

    CrewAI swarm watches a buyer's supplier list. Bright Data scrapes supplier LinkedIn / news / SERP daily → Granite (on MI300X) extracts risk signals (layoffs, lawsuits, leadership churn, sanctions hits) → Perplexity Comet drives the buyer's CRM in-browser to file the supplier-review ticket.

    Bright Data AMD MI300X Perplexity Comet IBM Granite CrewAI
  2. #2

    "Ground Truth" RAG for Investor Memos

    Most investor-research tools hallucinate because they RAG over stale PDFs. Every claim in this one must cite a Bright Data SERP / scraper result from the last 24h. Gemma on MI300X for synthesis; LangChain runs the citation-verification step. Pitch: no claim without a fresh URL.

    Bright Data AMD MI300X Google Gemma LangChain
  3. #3

    Marketplace Arbitrage Watcher

    Bright Data's Amazon + eBay scrapers feed a small Granite model (cheap to run on MI300X) that classifies arbitrage opportunities. A CrewAI agent drafts the listing on the destination marketplace and waits for human approval. Concrete dollar value per run makes for an easy demo.

    Bright Data AMD MI300X IBM Granite CrewAI
  4. #4

    Local-First Personal Research Analyst

    Perplexity Comet drives the browser; Bright Data takes over when Comet gets rate-limited; Gemma on MI300X runs the private summarization so the user's research history never leaves their tenant. Story: Comet's UX, your data sovereignty — a strong enterprise pitch.

    Perplexity Comet Bright Data AMD MI300X Google Gemma
  5. #5

    Compliance Diff Agent

    Pick a regulated domain (GDPR, HIPAA, SEC filings). Bright Data watches the source pages; when text changes, Granite on MI300X produces a structured diff and a "what you must change in your policy" memo. Judges respond to regulated-vertical demos because the buyer is obvious.

    Bright Data AMD MI300X IBM Granite LangChain
  6. #6

    Job-Market Heatmap for a Specific Role

    Scrape LinkedIn + Indeed + company career pages via Bright Data hourly. Granite extracts skills / comp / remote-policy. Output: a daily heatmap of where, e.g., "Rust infra engineers paying >$250k remote-OK" cluster. Niche, very demoable, and the live-data angle is exactly what Bright Data wants to showcase.

    Bright Data IBM Granite AMD MI300X
