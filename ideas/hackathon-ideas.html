The shape of a winner

// read of the room

The theme is agentic dev tools — coding agents, autonomous workflows, agent infrastructure. The sponsor stack tells you what the judges already use: InsForge for backend + auth + RLS, Vercel for the deploy surface and AI Gateway, Devin as the agent harness reference, Limrun for sandboxed code execution, Replicas for session replay. Pick an idea that stitches at least three of these together in a way that wouldn't be obvious from the marketing pages — that's the differentiator vs. 552 other teams.

★★★ Strongest pick

Replay → Repro

Production bug reports become deterministic local repros. A user hits an error in your app; an agent watches the Replicas session, reconstructs the request path + state, spins up a Limrun sandbox with that exact branch + seed data, and hands the developer a one-click "reproduce now" environment.

  • Closes the worst loop in debugging: "I can't reproduce it locally."
  • Demo: click an error in a fake dashboard → watch the sandbox boot → step into the failing line.
  • Genuinely novel — nobody owns this seam between session replay and agentic dev.

★★★ Strongest pick

Migration Pilot

Schema migrations you can trust. Point it at an InsForge project; it forks a branch project, runs the migration against production-shaped data, simulates rollback, surfaces a "blast radius" report (which RLS policies break, which queries get slower, which columns become unused), and only then files the PR.

  • Hits a real, painful problem every backend team has lost a weekend to.
  • InsForge branch projects + RLS audit is the killer combination — uses the sponsor in a way most demos won't.
  • Judges who've shipped DB migrations will feel it in their bones.

★★ Strong contender

PR Diplomat

Multi-agent code review with adversarial verification. A panel of cheap specialist agents (security, perf, correctness, "does this match the spec") reviews each PR; a tiebreaker agent only fires when they disagree. Posts a single, high-signal review — never 47 nitpick comments.

  • Differentiator: the disagreement-gated tiebreaker is the actual insight, not "we run 5 agents."
  • Plays directly to the Vercel Agent / Devin theme without copying either.
  • Cheap to demo: open a real OSS PR live, watch the verdict drop in.

★★ Strong contender

Drift Sentinel

An agent that lives in your Vercel logs. It learns the baseline shape of your traffic (latency percentiles per route, error fingerprints, log volume), and when something drifts, it correlates with the last 10 deploys, identifies the suspect commit, and opens a "rollback or investigate" thread in Slack with the diff annotated.

  • The "correlate to commit" step is the hard part — also the part judges will respect.
  • Uses Vercel's actual observability surface, not a generic LLM-on-logs pitch.

★★ Creative angle

Doc Twin

Docs that watch the code. Every time a PR lands, an agent re-verifies each documented code snippet against the live repo — runs it in a Limrun sandbox, checks function signatures, flags drift, and opens a single "your docs lie now" PR with the minimal fix.

  • Massive latent market — every fast-moving SDK has rotten docs.
  • Limrun is the perfect harness; nobody else will use it this way.

★★ Creative angle

Spec → Stack

One paragraph of product spec → a working full-stack app deployed to a preview URL in <90 seconds. InsForge provisions auth + DB + storage + RLS from the spec; Vercel scaffolds the Next.js front-end; a Devin-style agent loops on the build until preview is green.

  • Crowd-pleaser demo. Risk: feels like every other "v0-but-fuller" pitch unless the InsForge backend-provisioning bit is genuinely better.
  • Win by going narrow — "spec → CRUD admin panel with auth" is more impressive than "spec → anything," because it actually works.

★ Sleeper

Onboarding Compiler

Point it at a repo; it ships back a personalized day-one playbook — narrated codebase tour, sandboxed exercises in Limrun, a "fix this real (closed) issue from git history" challenge, and a final repo-shaped quiz. Cuts new-hire ramp from weeks to hours.

  • Underserved problem; engineering managers will go feral for this.
  • Limrun's exact use case. Easy to make beautiful.

★ Sleeper

Flake Court

Watches your CI for flaky tests, automatically opens a sandbox, reruns the failure 200 times with controlled jitter, classifies the flake (timing / network / shared state / true bug), and either quarantines, fixes, or escalates. Closes the case with a one-paragraph verdict.

  • Tiny scope, sharp demo: "watch this red CI go green in 90 seconds."
  • The classification taxonomy is the moat, not the agent loop.

How they'll judge it

// inferred from sponsor mix

① Live demo

Does it work end-to-end on stage, on flaky conference wifi? Pre-record a fallback. Land the wow moment in the first 30 seconds.

② Sponsor depth

Did you use the sponsor stack in a way the sponsor themselves would brag about? Surface-level wrappers lose; non-obvious integrations win.

③ Engineer-real

Would a working engineer install this on Monday? The room is dev-tools founders. They'll smell a toy.

④ Agentic core

Is the agent doing something only an agent could do — multi-step, stateful, error-recovering — or is it a prompt with a wrapper?
