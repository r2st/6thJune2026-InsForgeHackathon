# Pre-pitch checklist

Work backward from the absolute submission deadline in `docs/brief.md`.

## T-24h

- [ ] Pitch script v1 written and read aloud once
- [ ] Money shot identified and named in `docs/architecture.md`
- [ ] Sponsor APIs all returning data (cached snapshots saved to
      `assets/data/`)
- [ ] Branded landing visible (even if rough)

## T-12h

- [ ] Full end-to-end demo runs without manual repair
- [ ] First demo recording captured (`demo/recordings/`)
- [ ] First dry-run completed on the clock, written feedback in script

## T-4h

- [ ] Second dry-run done, script polished
- [ ] Q&A grill session done — top 5 questions have rehearsed answers
- [ ] Updated recording captured
- [ ] No new features being merged

## T-2h

- [ ] **Submit early**. Submission platform locked in. Iterate after.
- [ ] Third dry-run, on the actual demo laptop, on the actual network
- [ ] Cut list confirmed (which beats drop if running long)
- [ ] Fallback recording in a tab, ready to switch to

## T-30 min

- [ ] All non-essential apps quit
- [ ] Hotspot tested
- [ ] Mic / speaker / screen-share verified for the venue setup
- [ ] Storyteller has water, a script printout, and a watch they can see
