Confidence tiers

Hush doesn't
spam your PR queue.

Each finding is scored by diff size, policy blast radius, and similarity to past merged fixes. The action scales to the score.

85+
→ open PR

Small TOML diff. Single policy. Past similar diffs merged. Ready for review.

60-85
→ draft PR

Real, reproducible on the fork. Fix touches more than one policy. Humans decide.

<60
→ issue

Anomaly is real. Replay didn't reproduce cleanly. Files an issue with clip + log diff.
