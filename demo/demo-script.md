# Demo script (operator notes)

Step-by-step for whoever drives the keyboard during the pitch. Reads like
a checklist, not prose.

## Pre-demo (T-15 min)

- [ ] Laptop on charger, not battery
- [ ] Wifi reliable — phone hotspot as backup
- [ ] All sponsor APIs respond (run `scripts/preflight.sh`)
- [ ] Browser: only the demo tab open, no notifications
- [ ] Recording fallback (`demo/recordings/latest.mp4`) queued in another tab
- [ ] Zoom level set so judges in the back can read
- [ ] Slack / iMessage / email quit (no DND notifications mid-pitch)
