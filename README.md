## First-time setup

1. Fill in `docs/brief.md` with the actual hackathon brief, sponsors, prizes,
   judging criteria, and deadlines. Everything downstream keys off this.
2. Skim `agents/roles.md` and assign humans/agents to the four roles.
3. Seed `agents/inbox/` with the first wave of tasks (use
   `agents/_template.md`).
4. Read `demo/checklist.md` so the pre-pitch flow is in your head from hour 1.
