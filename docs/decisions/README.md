# Architecture Decision Records

Short notes on choices that another agent might second-guess. One file per
decision. Naming: `NNNN-kebab-title.md` (e.g. `0001-pick-nextjs.md`).

## Template

```markdown
# NNNN — <title>

- **Date:** YYYY-MM-DD
- **Status:** proposed | accepted | superseded by NNNN
- **Decider(s):** <agent or human>

## Context
Why this came up. What were we trying to do?

## Decision
What we chose, in one or two sentences.

## Alternatives considered
- Option A — why not
- Option B — why not

## Consequences
What this makes easy. What this makes hard. What we'll regret if it's wrong.
```
